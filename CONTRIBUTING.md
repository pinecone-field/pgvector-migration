# Contributing

Thanks for helping improve the pgvector migration guide. To report a bug,
request a feature, or suggest a documentation improvement, please
[file a GitHub issue](https://github.com/pinecone-field/pgvector-migration/issues/new).

Include the following when relevant:

- A clear description of the problem or proposed improvement.
- Steps to reproduce the problem.
- The expected and actual behavior.
- Your Python, PostgreSQL, pgvector, and Pinecone SDK versions.
- Relevant logs or error messages with secrets removed.

Before filing, please check the existing issues for a similar report. Never
include API keys, database credentials, customer data, or other sensitive
information in an issue.
